# Level 3 tournament manager

This repo sets up Python, NiceGUI and SQLite3 Editor. Write your own interface, database and tournament rules in Python and SQL. Use fictional data.

## Run your app

1. Open your Codespace and wait for setup to finish.
2. Once you have written a NiceGUI app in `app.py`, open **Terminal → New Terminal** and run `.venv/bin/python app.py`.
3. Use port **8080** for your app. In **Ports**, choose **Open in Browser** beside 8080. Keep the port **Private**.

Open your database file in **SQLite3 Editor** to inspect its tables. Keep the database file you need for your submission; it is not ignored by Git. Stop the running app before committing database changes.

## Finish a session

In **Source Control**, enter a short commit message, choose **Commit**, then **Sync Changes**. Wait for sync to finish. Go to [your Codespaces](https://github.com/codespaces), open the **…** menu and choose **Stop codespace**. Closing the browser tab does not stop it.
